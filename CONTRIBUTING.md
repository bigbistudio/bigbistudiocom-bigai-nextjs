# Contributing

This repository is the **real-world use case of the [bigA.i Workflow Next.js Template](https://github.com/bigbistudio/bigai-workflow-nextjs)**.

It is public to demonstrate how the template is adapted and extended to build the [www.bigbistudio.com](https://www.bigbistudio.com) website.

## Contributing to the Template

If you would like to contribute code, improvements, features, documentation, or reusable components to the underlying template, please contribute directly to the:

**[bigA.i Workflow Next.js Template](https://github.com/bigbistudio/bigai-workflow-nextjs)**

Please read its [CONTRIBUTING.md](https://github.com/bigbistudio/bigai-workflow-nextjs/blob/main/CONTRIBUTING.md) for development setup, contribution guidelines, commit conventions, and pull request requirements.

## This Repository

Changes to this repository are primarily related to the implementation of **[www.bigbistudio.com](http://www.bigbistudio.com)** and are not intended to evolve the bigA.i template itself.

For questions or issues specifically related to the website implementation, feel free to open an issue in this repository.
